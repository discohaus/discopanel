---
title: BlueMap
description: Render your world into an interactive 3D map you can open in a web browser.
---

BlueMap renders your world into an interactive 3D map you can open in a web browser and share with your players. It reads the world read-only, so it can't hurt anything. Give it a couple of minutes after the first start - rendering a whole world takes a while.

The map's URL is shown in the module's details once it's running.

:::note
BlueMap is a third-party project - DiscoPanel runs the official [BlueMap](https://bluemap.bluecolored.de/) image as a module.
:::
